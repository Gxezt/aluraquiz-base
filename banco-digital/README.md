# Pixel Bank 🏦 — app de banco digital (projeto de estudo)

Projeto de estudo/portfólio **inspirado** na experiência de bancos digitais brasileiros.
Marca, nome e visual são fictícios — não é afiliado a nenhum banco real.

## Stack
- React 19 + TypeScript
- Vite

## Rodando
```bash
npm install
npm run dev
```
